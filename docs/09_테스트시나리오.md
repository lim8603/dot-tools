## 1. 개요

본 문서는 DevSwitcher Tools v1.0.0의 테스트 전략(계층·범위·도구)과 테스트 시나리오,
그리고 릴리즈 시점의 최종 검증 결과를 정의·기록한다.

- **검증 대상**: VSCode 확장 `lim8603.devswitcher-tools` — 감지·상태바 칩·빌드/실행/디버그·watcher·프로파일 export/import·Doctor·시작 마법사(F20)·Run Group(준비 감지 포함)·키보드 단축키
- **기준 문서**: `.cowork/05_verification/test_strategy.md`(전략), `.cowork/05_verification/verification_evidence.md`(증거 인덱스), `.cowork/05_verification/test_case.md`(케이스 상세)
- **v1.0.0 최종 수치**: 단위 테스트 **268 passing** · 통합 테스트 **3 passing** · check-types / lint / esbuild prod **클린**
- **v1.3.0 최종 수치**: 단위 테스트 **379 passing** · 통합 테스트 **6 passing** · check-types / lint / esbuild prod **클린**

> **【v1.3.0】 통합 테스트가 3 → 6으로 늘어난 이유**는 커맨드가 늘어서가 아니라, **단위 테스트로는 확인할 수 없는 전제**가 생겼기 때문이다. `devSwitcher.scan.exclude`는 VSCode glob 엔진이 **최상위 중괄호 목록**(`{패턴A,패턴B}`)을 받아준다는 가정 위에 서 있는데, 기존 스캔은 경로 *안쪽* 중괄호만 써 왔다. 이 가정이 조용히 깨지면 스캔이 아무것도 제외하지 않거나 전부 제외한다 — 실 호스트에서만 판정 가능하므로 통합 테스트 3건을 추가했다(기준선·제외 동작·과다제외 아님).

## 2. 테스트 전략

### 2.1 테스트 피라미드 (3계층)

| 계층 | 범위 | 도구 | 실행 방법 | v1.0.0 현황 |
|------|------|------|-----------|-------------|
| **Unit** | vscode 무의존 순수 코어 — 파서(cargo/go/node)·상태 판정(reconcile)·호출 오버레이·프로파일 export·진단(diagnostics)·argsLine·이름 검증·템플릿·Run Group 계획/검증/스테이지·시퀀서(취소 포함)·준비 감지(readiness)·webview 스크립트 문법 가드·단축키 목록 · **【v1.3.0】 스캔 제외 글롭(scanExclude)·삭제 안전장치(cleanPlan)·브리지 캐시/peek 계약** | mocha (`out/test/unit`, `.mocharc.json`) | `npm run test:unit` (CI 가능) | **379 passing** (v1.0.0: 268) |
| **Integration (auto)** | 확장 활성화 · 커맨드 기여(16 커맨드) · 설정 페이지 오픈 | `@vscode/test-electron` + `@vscode/test-cli` (`.vscode-test.mjs`) | `npm run test:integration` (VSCode 호스트 필요) | **3 passing** (스모크) |
| **Manual (E2E)** | 칩 선택·빌드/실행/디버그·watcher·export/import·Doctor·시작 마법사·Run Group·단축키·WSL | 사람 F5 (Extension Development Host) | `test_case.md` §2 체크리스트 | **21 Pass · 2 Partial · 1 Known Issue(TC-11)** |

- 순수 함수 분리 원칙(`coding_convention.md`)에 따라 로직 대부분을 **Unit 계층에서 빠르게** 검증한다. vscode API 결합부는 Integration 스모크 + Manual 체크리스트로 커버한다.
- 단위/통합 스펙 분리: `.mocharc.json`은 `out/test/unit/**`만, 통합은 `.vscode-test.mjs`가 `out/test/integration/**`을 대상으로 한다.

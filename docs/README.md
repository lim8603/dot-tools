## v1.3.0 개정 요약

v1.0.0에서 13종을 생성한 뒤 v1.1.0~v1.2.1의 변경이 일부 문서에만 반영되어 있었다. v1.3.0에서 **누적분을 한 번에** 반영했다.

| 문서 | 반영한 누적 변경 |
|------|-----------------|
| 01 요구사항 | FR-015~019 추가 (언어 필터·VS 어댑터·**부작용 없는 조회**·스캔 제외·정리 기능). FR-004가 v1.2.1까지 깨져 있었다는 사실 명시 |
| 02 도메인 | 용어 추가 — probe · 빌드 트리 · Clean/Delete · 스캔 제외 · fail-open · 솔루션/멤버 |
| 03 기능 | **F22~F26 신설**과 상세 (§3.1) |
| 04 화면 | VS 칩·언어 체크박스·계층 표시·"not listed yet"·첫 페인트 분리 |
| 05 WBS | MS-021~023 추가, 7번째 언어, v1.1.0~v1.3.0 릴리즈 표. **INT-002가 예약했던 버전 번호와 실제가 다름**을 명시 |
| 06 아키텍처 | ADR-019·020·021 추가 + "선택은 빌드가 아니다"/"정리는 구성을 유발하지 않는다" 결정 기록 |
| 07 API | `validateAction` · `createCleanTask` · `buildTreeDirs` · `opts.probe` · `actions.clean` · vs 어댑터 행 |
| 08 DB | **저장 스키마는 변경 없음**을 명시 (마이그레이션 불필요) |
| 09·10 테스트 | 단위 268 → **367**, 통합 3 → **6**, TC-A4~A6 · TC-25~29 |
| 11 릴리즈 노트 | v1.2.1 · v1.3.0 절 추가 |
| 13 사용자 메뉴얼 | **7번째 툴체인(Visual Studio)** · 새 설정 4종 · Clean/Delete 사용법 · 트러블슈팅 6건 |

## Known Issue (v1.0.0)

- **TC-11 (WSL 수동 검증)** — 확장은 원격 안전(remote-safe)하게 설계되었으나(`workspace.fs`, `extensionKind: ["workspace"]`), WSL 환경 수동 검증은 이번 릴리즈에서 수행하지 않고 Known Issue로 공지한다 (Human 결정 D-23, 릴리즈 비차단). 상세: [10_테스트케이스.md](10_테스트케이스.md).

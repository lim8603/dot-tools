# ADR-009 (DD-09) — 의존성 온디맨드 3단계 처리 (extensionDependencies 미사용)

## ADR ID
`ADR-009`

## 제목
어댑터별 필요 확장을 최초 사용 시점에 온디맨드 설치하고, `extensionDependencies` 하드 의존을 사용하지 않는다.

## 상태
`Accepted`

## 날짜
2026-08-13

---

## Context (맥락)
CodeLLDB 등 디버거 확장 의존성을 어떻게 처리할지 결정해야 한다. v1.0 원안은 `extensionDependencies`로 CodeLLDB를 하드 의존했다.

## Decision (결정)
`extensionDependencies`를 사용하지 않는다. 각 어댑터의 `requiredExtensions`를 최초 사용 시점에 확인·자동 설치(`workbench.extensions.installExtension`)한다. 의존성은 3단계(완전 자동 / 반자동 / 안내만)로 분류해 처리한다(Doctor, F19).

## 근거 / Consequences
- 다언어 확장에서 전 어댑터의 디버거 확장을 강제 동반 설치하는 것은 부적절하다(Python 사용자에게 CodeLLDB 강제 설치).
- 사용 시점 자동 설치가 가능하므로 하드 의존이 불필요하다.
- 우아한 성능 저하(Graceful Degradation, NFR-003) — 없는 것에 의존하는 기능만 비활성화.
- 원격 환경에서는 설치가 자동으로 원격 측에 이뤄진다(ADR-008).

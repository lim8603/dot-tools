# ADR-004 (DD-04) — v1 범위에 F15(features)·F16(run args)·F17(파일 감시) 포함

## ADR ID
`ADR-004`

## 제목
Cargo features 칩(F15), 실행 인자(F16), 매니페스트 파일 감시(F17)를 v1 범위에 포함한다.

## 상태
`Accepted`

## 날짜
2026-08-13

---

## Context (맥락)
개념설계 대비 v1 범위를 어디까지 둘지 결정해야 한다. 최소 범위 유지도 대안이었다.

## Decision (결정)
F15·F16·F17을 v1에 포함한다. 기각: v1 최소 범위 유지.

## 근거 / Consequences
- Rust 실사용에서 features 전환은 프로파일 전환만큼 빈번하다.
- 매니페스트 변경 감지(F17)는 실사용 필수에 가깝다.
- 일정 +2일 미만으로 실사용성이 크게 상승한다.
- Trade-off: v1 일정 증가(로드맵 §16에 반영).

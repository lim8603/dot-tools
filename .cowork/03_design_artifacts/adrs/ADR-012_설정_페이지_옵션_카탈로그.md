# ADR-012 — 설정 페이지(WebviewPanel) + 선언적 옵션 카탈로그

## ADR ID
`ADR-012`

## 제목
설정 UI를 (모달 다이얼로그가 아닌) `WebviewPanel` "설정 페이지"로 확정하고, 컴파일러/링커 등 옵션을 어댑터가 선언하는 "옵션 카탈로그"(설명·예제·타입·허용값) 기반의 마스터-디테일 브라우저로 편집한다. 기존 명칭 "설정 다이얼로그"를 "설정 페이지"로 정정한다.

## 상태
`Accepted`

## 날짜
2026-08-15

---

## ADR 필요성 판단

- 확장성: 옵션 목록을 어댑터 선언 데이터로 두는 구조는 언어 확장에 장기 영향을 준다(ADR-003 연장).
- 비용/UX: 폼 팩터(페이지 vs 뷰) 결정이 구현과 정보 구조를 좌우한다.
- 두 축이 얽혀 ADR로 남긴다.

---

## Context (맥락)

설정 페이지의 내용이 호출 구성 오버레이(ADR-011)로 크게 확장됐다: `(프로젝트 × 구성) × (컴파일러·링커·출력·env·빌드이벤트·실행인자)`. 또한 사용자 요구(세션 #002): 개발자가 컴파일러 옵션을 자세히 모르는 경우가 많으니 **옵션 목록 + 선택 옵션의 설명·예제 + 값 에디터**를 제공하자.

한편 기존 문서는 이 UI를 "설정 다이얼로그"라 불렀으나, 실제 계획된 메커니즘은 `WebviewPanel`(에디터 탭)로 **다이얼로그가 아니었다**. VS Code에는 리치 폼을 담는 진짜 모달 다이얼로그가 없다(모달은 QuickPick·InputBox·showMessage뿐). 명칭과 실제가 어긋나 있었다.

---

## Decision Drivers (결정 요인)

- 마스터-디테일(목록 | 상세 | 에디터)은 가로 폭이 필요하다.
- VS "속성 페이지(Property Pages)" 메타포와 정합.
- 빠른 전환은 이미 상태바 칩/QuickPick가 담당 → 페이지는 깊은 구성 전용.
- 어댑터 무지 UI(INV-2) 유지: 옵션 목록도 어댑터가 선언한다.

---

## Options Considered (검토한 옵션)

### Option A: `WebviewPanel` 설정 페이지(에디터 탭) — 채택
- 장점: 넓은 폭, 속성 페이지 메타포, 리치 카탈로그(설명·예제) 표시에 적합.
- 단점: 탭을 열어야 함 — 단, 빠른 전환은 칩이 보완.

### Option B: `WebviewView` (사이드바/하단 도킹)
- 장점: 상시 접근, 토글 편리.
- 단점: 좁아서 마스터-디테일 + 예제 표시가 답답.

### Option C: 모달 다이얼로그
- 기각: VS Code에 리치 폼용 모달이 없다.

---

## Decision (결정)

**Option A** — `WebviewPanel` "설정 페이지"로 확정하고 명칭을 정정한다(다이얼로그 → 페이지).

- **레이아웃**: 상단 `프로젝트 / 구성(profile)` 스위처, 좌측 카테고리, 중앙 상세(카탈로그: 설명·예제·허용값·기본값), 값 에디터(타입 인식: enum 드롭다운 / bool 토글 / 숫자 / 텍스트), 하단 **적용 명령 미리보기**(ADR-011).
- **옵션 카탈로그**: 각 어댑터가 옵션 메타데이터(`id·설명·예제·타입·허용값·기본값·주입방식`)를 **선언**(번들 데이터). UI는 카탈로그만 렌더 → 언어 무지 유지(ADR-003 연장). v1은 cargo 카탈로그만 실데이터.
- **카테고리 가변**: 설정 페이지 탭/카테고리도 어댑터가 선언 → Python(`actions.build=false`)은 컴파일러/링커/출력을 표시하지 않고 환경변수·검색경로(`PYTHONPATH`)·실행 인자를 표시(리트머스, INV-2).
- **역할 분담**: 상태바 칩/QuickPick = 빠른 전환(빌드 직전 매번); 설정 페이지 = 깊은 구성·학습(가끔).

---

## Consequences (결과)

### 긍정적
- 옵션을 몰라도 설명·예제·타입 에디터로 안전하게 편집.
- 어댑터가 카탈로그·카테고리를 선언 → UI 무변경으로 언어 확장.
- 명령 미리보기로 학습 효과 + 투명성.

### 부정적 / Trade-off
- 옵션 카탈로그는 큐레이션 데이터 → 툴체인 버전 상승 시 갱신 부담("rustc X 기준" 등 태깅으로 완화).
- `WebviewPanel`은 에디터 탭을 점유 — 빠른 전환은 칩으로 보완.

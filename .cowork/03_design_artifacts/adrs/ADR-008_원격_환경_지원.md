# ADR-008 (DD-08) — 원격 환경 지원 (extensionKind: workspace)

## ADR ID
`ADR-008`

## 제목
WSL·Dev Containers·Remote-SSH를 v1 지원 범위로 두고 `extensionKind: ["workspace"]`로 선언한다.

## 상태
`Accepted`

## 날짜
2026-08-13

---

## Context (맥락)
원격 개발 환경 지원 여부를 정해야 한다. 로컬 전용 v1도 대안이었다.

## Decision (결정)
원격(WSL/컨테이너/SSH)을 v1 지원 범위로 포함하고, `extensionKind: ["workspace"]`를 선언해 원격 연결 시 항상 원격(워크스페이스) 측에서 실행되게 한다. 원격 안전 규칙(§12.2)을 준수한다.

## 근거 / Consequences
- VSCode Remote 아키텍처에서는 확장 호스트가 원격 측에서 실행되므로, 안전 규칙만 지키면 추가 구현 없이 WSL/컨테이너/SSH 전체가 열린다.
- ADR-005(경로를 cargo에 위임)·ADR-006(Uri 기반 스캔)이 이미 원격 안전이라 비용이 낮다.
- 제약: 경로는 `vscode.Uri` 기반, OS 경로 형식 가정 금지. 툴체인 존재를 가정하지 않고 매 환경 재진단(F19).
- 한계: "한 창 = 한 환경" — 같은 창에서 Windows↔WSL 환경 전환은 불가(v2 백로그).

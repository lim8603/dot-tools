# ADR-007 (DD-07) — SSOT 파사드: 값은 캐노니컬 파일에만

## ADR ID
`ADR-007`

## 제목
값은 각 언어의 캐노니컬 파일에만 두고, 확장은 포인터와 선택 상태만 소유한다(SSOT 파사드).

## 상태
`Accepted`

## 날짜
2026-08-13

---

## Context (맥락)
빌드 플래그·프로파일 정의 같은 실제 값을 확장이 복제할지, 원천 파일에만 둘지 결정해야 한다.

## Decision (결정)
값은 캐노니컬 파일(`Cargo.toml` 등)에만 존재한다. 확장은 값을 복제하지 않고 "어느 어댑터의 어느 파일을 보는지"에 대한 포인터와 현재 선택 상태만 소유한다. (개념설계서 원칙 계승)

## 근거 / Consequences
- 값 이중화가 없어 원천과 확장 상태가 어긋날 여지가 없다.
- 설정 편집(설정 패널)은 값을 자체 저장하지 않고 캐노니컬 파일을 국소 편집한다(§8.7).
- ADR-001(DD-01)은 이 원칙의 **저장 위치만** 정정한 것(선택 상태 = workspaceState).
- Trade-off: 어댑터마다 파일 포맷(TOML/JSON/XML) 파싱·국소 편집 구현이 필요.

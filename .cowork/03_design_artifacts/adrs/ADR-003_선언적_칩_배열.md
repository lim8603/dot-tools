# ADR-003 (DD-03) — Capabilities를 선언적 칩 배열(ChipDescriptor[])로 정의

## ADR ID
`ADR-003`

## 제목
어댑터 능력을 boolean 고정 구조체가 아니라 선언적 칩 배열(`chips: ChipDescriptor[]`)로 정의한다.

## 상태
`Accepted`

## 날짜
2026-08-13

---

## Context (맥락)
개념설계는 어댑터 능력을 boolean 5개(profile/architecture/environment/target/build) 고정 구조체로 선언했다. 새 칩(features 등)을 추가하려면 이 구조가 매번 바뀐다.

## Decision (결정)
어댑터가 임의의 칩을 선언하는 배열 구조(`ChipDescriptor[]`)로 정의한다. 기각: boolean 5개 고정 구조체.

## 근거 / Consequences
- boolean 고정 구조는 새 칩 추가 시마다 인터페이스가 깨진다.
- 배열 구조는 상태바/QuickPick/설정 UI 코드 수정 없이 어댑터 고유 칩을 추가할 수 있다. **F15(features)가 첫 수혜자.**
- 상태바는 `chips` 배열을 순회하며 그리므로 어댑터 추가 시 UI 코드 무변경(NFR-005, 이 설계의 핵심).
- Trade-off: 칩별 메서드(`listProfiles` 등)가 `ChipDescriptor.listItems()`로 통합돼 어댑터 구현이 약간 추상화됨.

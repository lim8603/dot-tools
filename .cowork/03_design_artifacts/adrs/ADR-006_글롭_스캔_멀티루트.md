# ADR-006 (DD-06) — 프로젝트 감지를 글롭 스캔 + 멀티루트 순회로

## ADR ID
`ADR-006`

## 제목
프로젝트 감지를 `workspace.findFiles('**/Cargo.toml')` 글롭 스캔 + 멀티루트 워크스페이스 순회로 수행한다.

## 상태
`Accepted`

## 날짜
2026-08-13

---

## Context (맥락)
프로젝트 감지 방식을 정해야 한다. 개념설계 원안은 워크스페이스 루트의 매니페스트 존재만 확인했다.

## Decision (결정)
글롭 스캔(`**/Cargo.toml`, `target/` 제외) + 멀티루트 폴더별 순회. 기각: 루트 파일 존재 확인.

## 근거 / Consequences
- 루트만 확인하면 하위 폴더 프로젝트와 멀티루트 구성을 놓친다.
- `ProjectInfo.id = ${adapterId}:${상대경로}` — 기계 독립적이라 F12 공유에 유리.
- 어댑터는 `detect(root)` 대신 `manifestGlobs` + `listProjects(manifests: Uri[])` 형태로 파일 목록을 넘겨받는다.
- Uri 기반이라 원격 환경에 안전(DD-08에 기여).

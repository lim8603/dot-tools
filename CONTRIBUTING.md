# Contributing

Thanks for your interest in DevSwitcher Tools!

**This is a personal project and does not accept external code contributions.**
Pull requests are closed automatically by a workflow — please don't spend time
preparing one.

What *is* welcome:

- **Bug reports and feedback** — please [open an issue](https://github.com/lim8603/dot-tools/issues).
  For WSL/remote problems, include your environment details (see *Known
  limitations* in the README).
- **Using and sharing** the extension — it's MIT-licensed, so forking for your
  own use is of course fine.
